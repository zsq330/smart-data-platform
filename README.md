# 📊 智能数据清洗与可视化分析平台

一个基于 **Streamlit + Pandas + Plotly + 通义千问** 的数据清洗与可视化分析 Web 应用，商业 / 医疗 / 科研数据通用。

## ✨ 功能总览

| 模块 | 功能 |
|---|---|
| 📂 公共操作区 | 上传 CSV（自动识别 UTF-8 / GBK 编码）→ 一键清洗 → 清洗前后对比 → 导出 CSV |
| 🧹 通用清洗与探索 | 异常值检测（IQR 箱线图）、自选交互式图表（柱/折/饼/散点）、相关性热力图 |
| 💼 商业与市场分析 | 分类交叉分析表（含热力图）、中文文本词云图（jieba 分词）、对比图表 |
| 🔬 科研与深度学习预处理 | Z-score / Min-Max 标准化、特征分布直方图（偏度/峰度）、建模可用性检查 |
| 🤖 AI 智能报告 | 每个标签页内置 AI 洞察面板，生成【核心发现 / 原因分析 / 行动建议】三段式报告，可下载 .md |

内置三套示例数据（商业销售 / 医疗健康 / 科研实验），故意掺入缺失值、重复行和异常值，无需自备数据即可体验全部功能。

## 🚀 本地运行

```bash
# 1. 安装依赖（建议 Python 3.10+）
pip install streamlit pandas numpy plotly openai wordcloud matplotlib openpyxl jieba

# 2. 启动
streamlit run app.py
```

浏览器自动打开 http://localhost:8501

## 🔑 API Key 说明

- AI 报告功能需要**通义千问（阿里云百炼）**的 API Key，在页面左侧侧边栏输入（密码框，仅保存在浏览器会话内存中，代码里没有任何硬编码密钥）。
- 除 AI 报告外的全部功能（清洗、图表、词云、标准化）**无需 Key 即可使用**。
- 可选：设置系统环境变量 `DASHSCOPE_API_KEY` 作为输入框默认值。

## 🛡️ 隐私说明

数据全部在本地内存中处理；仅当点击「生成智能分析报告」时，数据的统计摘要（非原始数据）才会发送给大模型接口。
